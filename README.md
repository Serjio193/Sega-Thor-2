# Sega-Thor-2

Evidence-driven reverse engineering and progressive recompilation research for **The Story of Thor 2 / The Legend of Oasis** on Sega Saturn.

This repository contains only legal-safe source, tooling, configuration, documentation, and derived metadata. Original commercial disc images, extracted retail binaries, save states, RAM dumps, raw traces, and other copyrighted game data stay outside GitHub.

## Current status

**Active milestone:** `T2-M0 — Canonical Disc + Executable/Module Census`

No decompiler/recompiler architecture is considered final yet. External techniques are introduced one at a time, tested on a bounded Thor 2 slice, and only retained after evidence-backed validation.
